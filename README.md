# EconFunctions.jl

[![build](https://github.com/tpapp/EconFunctions.jl/workflows/CI/badge.svg)](https://github.com/tpapp/EconFunctions.jl/actions?query=workflow%3ACI)
[![Aqua QA](https://raw.githubusercontent.com/JuliaTesting/Aqua.jl/master/badge.svg)](https://github.com/JuliaTesting/Aqua.jl)

Julia package for functions commonly used in economic models.

The intention is to have numerically robust, well-tested implementations for the functions and their derivatives. Logarithm and similar domain transformations are used wherever they make sense.
